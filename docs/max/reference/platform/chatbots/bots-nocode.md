# Настройка сценариев работы бота с помощью конструктора

> Подключение к платформе MAX для партнёров и её сервисам — чат-ботам, мини-приложениям, каналам — доступно для юрлиц, ИП и самозанятых, которые являются резидентами РФ. Подключение к сервису Цифрового ID доступно только для юрлиц и ИП (резидентов РФ)

Вы можете [создать бота](https://dev.max.ru/docs/chatbots/bots-create/create), только если у вас есть [верифицированный профиль организации, ИП или самозанятого](https://dev.max.ru/docs/maxbusiness/connection#%D0%92%D0%B5%D1%80%D0%B8%D1%84%D0%B8%D0%BA%D0%B0%D1%86%D0%B8%D1%8F) на платформе MAX для партнёров. Количество доступных для создания ботов зависит от профиля

## Конструктор сценариев бота

Конструкторы ботов предоставляют готовые шаблоны для создания сценариев ботов, а также инструменты для управления и аналитики. Это позволяет быстро запускать чат-боты без разработки и программирования.
Кроме того, конструкторы поддерживают интеграцию с AI-решениями, что позволяет автоматизировать рутинные задачи, например обзвон клиентов и приём заказов

Мы рекомендуем работать на платформах [официальных партнёров MAX](https://dev.max.ru/docs/partners-integration#%D0%9F%D0%BB%D0%B0%D1%82%D1%84%D0%BE%D1%80%D0%BC%D1%8B-%D0%BA%D0%BE%D0%BD%D1%81%D1%82%D1%80%D1%83%D0%BA%D1%82%D0%BE%D1%80%D1%8B%20%D1%87%D0%B0%D1%82-%D0%B1%D0%BE%D1%82%D0%BE%D0%B2).
Вы можете выборочно подключить встроенные сервисы для работы с клиентами, маркетингом и платёжными системами или полностью делегировать свои проекты

### Как работать с конструктором

1. Выберите любой конструктор из списка [официальных партнёров MAX](https://dev.max.ru/docs/partners-integration#%D0%9F%D0%BB%D0%B0%D1%82%D1%84%D0%BE%D1%80%D0%BC%D1%8B-%D0%BA%D0%BE%D0%BD%D1%81%D1%82%D1%80%D1%83%D0%BA%D1%82%D0%BE%D1%80%D1%8B%20%D1%87%D0%B0%D1%82-%D0%B1%D0%BE%D1%82%D0%BE%D0%B2), перейдите на сайт партнёра и зарегистрируйтесь. Рекомендуем работать на компьютере — в мобильной версии некоторые функции конструкторов могут быть недоступны
2. У разных конструкторов последовательность действий при настройке бота может отличаться, следуйте подсказкам на сайте сервиса.
   Заполните блоки и кнопки, настройте сбор данных, чтобы проанализировать эффективность вашего сценария после запуска бота

### Как добавить мини-приложения в MAX через конструктор

К боту с настроенным сценарием можно [подключить мини-приложение](https://dev.max.ru/docs/webapps/introduction). Для этого в настройках конструктора найдите MAX, укажите в нужном поле токен бота и активируйте интеграцию кнопкой или переключателем. Готово! Перейдите в мини-приложение

### Как отредактировать сценарий

После запуска чат-бота могут возникнуть ситуации, когда сценарий захочется отредактировать: переписать текст, добавить или убрать блоки, исправить опечатку.
Такие изменения необходимо вносить на сайте конструктора, в котором вы собирали бота
