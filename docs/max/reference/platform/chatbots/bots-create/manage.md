# Управление ботом на платформе

Помимо использования веб-версии [платформы MAX для партнёров](https://business.max.ru/self), управлять чат-ботом можно с помощью [мини-приложения «MAX для бизнеса»](https://max.ru/business_bot?startapp)

Шаги управления чат-ботом в веб-версии и мини-приложении «MAX для бизнеса» совпадают. Подробнее о работе с чат-ботом с помощью мини-приложения или бота читайте в [разделе «FAQ»](https://dev.max.ru/help/miniapp-main)

## Настройка приватности бота и добавление мини-приложения

После [модерации](https://dev.max.ru/docs/chatbots/bots-create/create#%D0%9C%D0%BE%D0%B4%D0%B5%D1%80%D0%B0%D1%86%D0%B8%D1%8F%20%D0%B1%D0%BE%D1%82%D0%B0) бота вам станут доступны настройки. Чтобы посмотреть их, перейдите в раздел платформы **Чат-боты**, выберите необходимого бота и нажмите **⋮** → **Настройки**

- **Чат-бот**:
  - **Токен доступа** — вы можете скопировать токен бота для его дальнейшей настройки, а также обновить его
  - **Приватность** — вы можете разрешить или запретить добавление бота в групповые чаты. По умолчанию стоит запрет
- **Мини-приложение**:
  - **Введите ссылку** — вы можете указать ссылку на мини-приложение для его привязки к боту
  - **Выберите кнопку открытия мини-приложения** — вы можете выбрать один из вариантов: **Открыть**, **Старт**, **Играть** или без названия (по умолчанию). Подробнее – [в разделе про мини-приложения](https://dev.max.ru/docs/webapps/introduction#%D0%9A%D0%B0%D0%BA%20%D0%B4%D0%BE%D0%B1%D0%B0%D0%B2%D0%B8%D1%82%D1%8C%20%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5%20%D0%B2%20MAX)

## Редактирование бота

> - Поменять данные бота можно только на платформе MAX для партнёров (отредактировать их в мессенджере MAX не получится) и только после прохождения [модерации](https://dev.max.ru/docs/chatbots/bots-create/create#%D0%9C%D0%BE%D0%B4%D0%B5%D1%80%D0%B0%D1%86%D0%B8%D1%8F%20%D1%87%D0%B0%D1%82-%D0%B1%D0%BE%D1%82%D0%B0). Если вы не хотите ждать её окончания, удалите бота и создайте нового с необходимыми данными
> - Изменить можно все данные бота, кроме ника

1. Перейдите на [платформу MAX для партнёров](https://business.max.ru/self) в раздел **Чат-боты**
2. Выберите необходимого бота и нажмите **→**
3. Внесите изменения в разделе **Основная информация** и нажмите **Сохранить** — бот будет отправлен на повторную [модерацию](https://dev.max.ru/docs/chatbots/bots-create/create#%D0%A1%D1%82%D0%B0%D1%82%D1%83%D1%81%D1%8B%20%D0%BC%D0%BE%D0%B4%D0%B5%D1%80%D0%B0%D1%86%D0%B8%D0%B8)

## Получение токена бота

После успешной проверки чат-бота сформируется **токен** — уникальный идентификатор бота, с помощью которого бот будет взаимодействовать с [API MAX](https://dev.max.ru/docs-api)

Чтобы скопировать токен бота:

1. Перейдите на [платформу MAX для партнёров](https://business.max.ru/self) в раздел **Чат-боты**
2. Выберите необходимого бота и нажмите **⋮** → **Настройки**
3. Справа от поля с токеном нажмите на значок копирования

![](/assets/chat_bots/bot_options.png)

![](/assets/chat_bots/integration_token.png)

*Получение токена бота*

Наличие токена означает, что бот зарегистрирован на платформе MAX для партнёров

> **Пример токена**  
>   
> `AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw`

Так как токен — это прямой доступ к боту, не рекомендуется хранить его в открытых источниках или передавать посторонним: они смогут завладеть ботом и управлять им от вашего имени. Если вы опасаетесь, что токен скомпрометирован, [обновите его](#%D0%9E%D0%B1%D0%BD%D0%BE%D0%B2%D0%BB%D0%B5%D0%BD%D0%B8%D0%B5%20%D1%82%D0%BE%D0%BA%D0%B5%D0%BD%D0%B0%20%D0%B1%D0%BE%D1%82%D0%B0)

Подробнее о том, как получить токен чат-бота с помощью [мини-приложения «MAX для бизнеса»](https://max.ru/business_bot?startapp) или [бота «MAX для бизнеса»](https://max.ru/business_bot), читайте в [разделе «FAQ»](https://dev.max.ru/help/miniapp-main)

## Обновление токена бота

1. Перейдите на [платформу MAX для партнёров](https://business.max.ru/self) в раздел **Чат-боты**
2. Выберите необходимого бота и нажмите **⋮** → **Настройки**
3. Справа от поля с токеном нажмите на значок обновления

## Удаление бота

![ℹ️](/assets/emoji/information_2139-fe0f.png) После удаления ваши клиенты не смогут пользоваться ботом. Удалённого бота нельзя восстановить

Чтобы удалить бота:

1. Перейдите на [платформу MAX для партнёров](https://business.max.ru/self) в раздел **Чат-боты**
2. Выберите необходимого бота и удалите его одним из способов:
   - Либо нажмите **⋮** → **Удалить**
   - Либо нажмите **→** и в разделе **Основная информация** выберите **Удалить чат-бот**
