# Об интеграции с сервисами партнёров

> Подключение к платформе MAX для партнёров и её сервисам — чат-ботам, мини-приложениям, каналам — доступно для юрлиц, ИП и самозанятых, которые являются резидентами РФ. Подключение к сервису Цифрового ID доступно только для юрлиц и ИП (резидентов РФ)

В разделе приведены сервисы-партнёры MAX: с их помощью бизнес, подключенный к [платформе MAX для партнёров](https://business.max.ru), может создавать, использовать и развивать инструменты для взаимодействия с клиентами через мессенджер

После [создания и модерации бота](https://dev.max.ru/docs/chatbots/bots-create/create) становится доступен [токен бота](#%D0%A2%D0%BE%D0%BA%D0%B5%D0%BD%20%D0%B1%D0%BE%D1%82%D0%B0%20%D0%B4%D0%BB%D1%8F%20%D0%B8%D0%BD%D1%82%D0%B5%D0%B3%D1%80%D0%B0%D1%86%D0%B8%D0%B8), с помощью которого вы можете подключить сервисы партнёров:

- [CRM-системы](#CRM-%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC%D1%8B) — для автоматизации рутинных операций и работы с клиентской базой: лидами, заявками, историей общения с клиентами
- [Чат-платформы](#%D0%A7%D0%B0%D1%82-%D0%BF%D0%BB%D0%B0%D1%82%D1%84%D0%BE%D1%80%D0%BC%D1%8B%20%D0%BF%D0%BE%D0%B4%D0%B4%D0%B5%D1%80%D0%B6%D0%BA%D0%B8) — для общения с клиентами через сервис партнёров
- [Платформы-конструкторы чат-ботов и мини-приложений](#%D0%9F%D0%BB%D0%B0%D1%82%D1%84%D0%BE%D1%80%D0%BC%D1%8B-%D0%BA%D0%BE%D0%BD%D1%81%D1%82%D1%80%D1%83%D0%BA%D1%82%D0%BE%D1%80%D1%8B%20%D1%87%D0%B0%D1%82-%D0%B1%D0%BE%D1%82%D0%BE%D0%B2) – для создания чат-ботов и мини-приложений без разработки
- [Заказная разработка](#%D0%97%D0%B0%D0%BA%D0%B0%D0%B7%D0%BD%D0%B0%D1%8F%20%D1%80%D0%B0%D0%B7%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B0) — для создания чат-ботов и мини-приложений под ключ

Помимо использования веб-версии [платформы MAX для партнёров](https://business.max.ru/self), выбрать партнёра для интеграции и получить токен можно с помощью [мини-приложения «MAX для бизнеса»](https://max.ru/business_bot?startapp)

Шаги выбора партнёров для интеграций в веб-версии и мини-приложении «MAX для бизнеса» совпадают

Список партнёров МАХ также можно посмотреть на платформе в разделе **Интеграции** → **Подключить**.
Здесь вы можете отфильтровать сервисы: выберите категории, которые вас интересуют, — отобразятся все партнёры, которые подходят хотя бы под одну из них.
Дополнительно или вместо фильтрации используйте строку поиска — чтобы сразу найти нужный сервис по названию

## Токен бота для интеграции

Для подключения к сервисам партнёров используйте токен бота. Чтобы скопировать токен бота:

1. Перейдите на [платформу MAX для партнёров](https://business.max.ru/self) в раздел **Чат-боты**
2. Выберите необходимого бота и нажмите **⋮** → **Настройки**
3. Справа от поля с токеном нажмите на значок копирования

![](/assets/chat_bots/bot_options.png)

![](/assets/chat_bots/integration_token.png)

*Получение токена бота*

Подробнее о том, как получить токен с помощью [мини-приложения «MAX для бизнеса»](https://max.ru/business_bot?startapp) или [бота «MAX для бизнеса»](https://max.ru/business_bot), читайте в [разделе FAQ](https://dev.max.ru/help/miniapp-main)

### Платформы-конструкторы чат-ботов

Платформы ботов предоставляют готовые шаблоны для создания сценариев ботов, а также инструменты для управления и аналитики. Всё это позволяет быстро запустить чат-бот без разработки и программирования.
Кроме того, конструкторы поддерживают интеграцию с AI-решениями, что позволяет автоматизировать рутинные задачи, например обзвон клиентов и приём заказов

Вы можете разработать чат-бот в MAX с помощью такого конструктора. Также некоторые сервисы предоставляют возможность создания мини-приложений без разработки. Список рекомендуемых партнёров представлен ниже

## Как стать партнёром

Чтобы стать официальным партнёром, необходимо заполнить заявку через платформу:

1. На [платформе](https://business.max.ru/self) перейдите в раздел **Интеграции** → **Подключить**
2. Нажмите **Стать партнёром**

![](/assets/partners-integration/integration_card_main_page.png)

![](/assets/partners-integration/integration_get_partner.png)

*Как стать партнёром*

3. Заполните форму и нажмите **Отправить заявку**

 **Обратите внимание на требования к заполнению формы** 

- Укажите название сервиса (**обязательно**)
- Загрузите логотипы для светлой и тёмной темы (**обязательно**)  
   Формат — SVG, не более 5 Мб каждый, только горизонтальная ориентация, должен содержать обязательно текстовое название и опционально графический знак
- Добавьте описание сервиса (**обязательно**): тип, что делает и какую пользу даёт  
   Формат — до 180 символов. Рекомендуем избегать общих и маркетинговых фраз, формулировать ёмко и содержательно — описание должно давать чёткое представление о вашем сервисе
- Выберите функции, которые предоставляет сервис (обязательно): **CRM**, **Заказная разработка**, **Конструкторы мини-приложений**, **Платформы чат-ботов**, **Чат-платформы**
- Укажите ссылку на сайт (**обязательно**)  
   Формат — должна начинаться с `https://`, может содержать латиницу, кириллицу, точки и дефисы
- Укажите контакты для связи — нужно указать **обязательно хотя бы один из**:   
  • Номер телефона. Формат — `+7(999)999-99-99`  
  • Электронная почта. Формат — `example@mail.ru`
- Загрузите дополнительные материалы, например, презентацию о вашей компании (**опционально**)  
   Формат — PDF, один файл до 10 Мб

![](/assets/partners-integration/integration_get_partner_empty_form_1.png)

![](/assets/partners-integration/integration_get_partner_empty_form_2.png)

*Как стать партнёром (форма заявки)*

  

После успешной отправки формы вы увидите соответствующее уведомление

![Уведомление об отправке заявки на партнёрство](/assets/partners-integration/integration_get_partner_empty_form_sending_confirm.png "Уведомление об отправке заявки на партнёрство")

Мы обязательно рассмотрим заявку и свяжемся с вами по указанным контактам, если увидим возможность для партнёрства

Когда запрос отправлен, кнопка **Стать партнёром** пропадает, — заявку можно отправить только один раз. Посмотреть или отредактировать отправленный запрос, а также узнать статус рассмотрения через платформу пока нельзя. Если вы хотите изменить данные в заявке, напишите [в чат «Поддержка MAX для бизнеса»](https://max.ru/business_support_bot)

## Как найти партнёра на платформе

1. На [платформе](https://business.max.ru/self) перейдите в разделе **Интеграции** → **Подключить**
2. Выберите категории, которые вас интересуют, — отобразятся все сервисы, которые подходят хотя бы под одну из них. Ознакомьтесь с кратким описанием представленных партнёров. Если вы ищете конкретный сервис, используйте строку поиска, чтобы найти его сразу по названию. Чтобы узнать подробнее о работе заинтересовавшего сервиса и интеграции с ним, нажмите на его карточку, — вы перейдёте на сайт партнёра

Если нужного сервиса на платформе и в документации ещё нет, следите за обновлениями: количество партнёров растёт, и мы регулярно пополняем их список
