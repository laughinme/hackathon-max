## Команды для чат-бота

Добавить команды для чат-бота можно с помощью метода [PATCH `/me/commands`](https://dev.max.ru/docs-api/methods/PATCH/me/commands)

Настроить логику сценариев работы чат-бота так, чтобы он выполнял необходимые вам действия в ответ на команды или слова, отправленные в чат, можно с помощью библиотек [JavaScript](https://dev.max.ru/docs/chatbots/bots-coding/js) и [Golang](https://dev.max.ru/docs/chatbots/bots-coding/go). Примеры использования библиотек для работы с чат-ботом читайте в [разделе «Примеры создания ботов»](https://dev.max.ru/docs/chatbots/bots-coding/examples)

Вы можете добавить команды в [кнопки](https://dev.max.ru/docs-api/use-cases/sending-messages/keyboard) с типом `callback`, которые чат-бот будет присылать сообщением
