## Правила для этой папки

- Ничего не редактировать по смыслу: это первоисточник для ссылок из `docs/`.
- Новые официальные материалы (шаблон презентации, FAQ организаторов, письма) складывать сюда и добавлять строку в таблицу выше.
- Выгрузки чатов и всё с персональными данными — в `case/raw/` (в `.gitignore`).
