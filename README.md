# hackathon-max — «Домовой» (рабочее название)

Чат-бот и мини-приложение в мессенджере MAX для трека «Умный город» хакатона MAX 2026: заявка из домового чата с нормативным сроком, очередь для управляющей организации, эскалация при просрочке.

Этот README будет заменён на инструкцию для проверяющих по чек-листу кейса (запуск одной командой, сценарий проверки, ограничения). Пока навигация:

- [AGENTS.md](AGENTS.md) — точка входа: что читать, карта репозитория, правила.
- [docs/STATUS.md](docs/STATUS.md) — текущее состояние и план.
- [docs/CASE_BRIEF.md](docs/CASE_BRIEF.md) — кейс и критерии.
- [docs/PRODUCT.md](docs/PRODUCT.md) — продукт и сценарий.
- [case/](case/README.md) — материалы организаторов.
