## Заметки для Claude Code

- Язык общения и документов — русский; код, идентификаторы и коммиты — английский.
- Документацию библиотек (FastAPI, SQLAlchemy, httpx, `maxapi`, React, Vite, `@maxhub/max-ui`) сверять через Context7, а не по памяти. Для MAX Bot API источник — локальный снимок `docs/max/` плюс `docs/max/reference/api/changelog-api.md`.
- Никогда не печатать значение `MAX_TOKEN` и содержимое `.env`; при проверке API читать токен из окружения в той же shell-команде.
- Перед кодом в `backend/` перечитать `docs/ARCHITECTURE.md` §2 (правила слоёв) и `docs/CONTRACTS.md`; новые use case'ы — по одному на файл, с тестом.
- Пакетный менеджер Python — `uv`; линт `ruff`, типы `pyright`; фронтенд — `npm` + `eslint`. Запускать проверки перед тем, как сообщать о готовности.
- В конце сессии обновлять `docs/STATUS.md` и при необходимости `docs/DECISIONS.md`; не плодить новые документы, если тема уже есть.
- Субагенты — только для веб-ресерча, на Sonnet/Opus. Локальные файлы читать самому.
